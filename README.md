## 🏛️ Project Positioning & Context
> [!IMPORTANT]
> **Prototype & Integration-Ready Intelligence Layer:**  
> ShramAI is an India-specific, research-grade labour compliance intelligence prototype designed around the principles of **proactive, evidence-backed, and human-supervised** compliance and inspection intelligence.  
> - **Not an Official Government System:** ShramAI is not claimed to be an official Government of India portal or a live modification of the official Shram Suvidha production platform.  
> - **Inspection Philosophy:** ShramAI draws conceptual inspiration from international risk-based inspection methodologies (such as MIRA Albania) tailored specifically to the **Four Labour Codes of India** (Code on Wages, Industrial Relations Code, Social Security Code, and OSH&WC Code).

## 🔑 Key Innovation Pillars

1. **Deterministic Rule Engine (Not Hallucinating LLMs):**  
   Statutory compliance conditions are validated deterministically via structured JSON rules (`wage_rules.json`, `attendance_rules.json`, etc.). LLMs do not invent legal compliance status; they summarize and cite findings.

2. **Cross-Document Anomaly Engine:**  
   Detects subtle discrepancies across multi-source registers (e.g. Employee Register = 62 workers, Attendance Register = 61 workers, Wage Sheet = 57 workers, Payroll = 59 workers).

3. **Ground-Truth Labour Law RAG:**  
   Every flagged non-compliance is mapped directly to authoritative provisions from the Indian Labour Codes and official notifications with source attribution.

4. **Calibrated ML Risk Scoring & SHAP Explainability:**  
   Numerical risk probabilities (0–100) are generated by an XGBoost model trained on establishment risk features, not hallucinated by generative models. SHAP values explain exact positive and negative contributors for every establishment score.

5. **Human-in-the-Loop & Closed-Loop Learning:**  
   Inspectors make final decisions (Confirm, Reject, Request More Evidence), which feed back into continuous model validation and recalibration.

## 🛠️ Getting Started (Phase 0)

### Prerequisites
- Python 3.11+
- Node.js 18+ (Node 20+ recommended)
- Git
- Docker & Docker Compose (optional for containerized deployment)

### 1. Backend Setup
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
API Documentation will be available at `http://127.0.0.1:8000/docs` and Health endpoint at `http://127.0.0.1:8000/api/v1/health`.

### 2. Frontend Setup
```powershell
cd frontend
npm install
npm run dev
```
Access the application at `http://localhost:5173`.

### 3. Docker Deployment
```powershell
docker-compose up --build
```
